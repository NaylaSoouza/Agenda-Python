# 📅 Agenda de Tarefas em Python

Aplicação de agenda desenvolvida em **Python** durante meus estudos de programação.

O projeto foi desenvolvido com o objetivo de colocar em prática conceitos de programação, lógica e desenvolvimento de interfaces gráficas.

## 📸 Demonstração

![Agenda de Tarefas](agenda.png)

## 🖥️ Sobre o projeto

A **Agenda de Tarefas** é uma aplicação desenvolvida para auxiliar na organização de atividades por meio de uma interface gráfica simples e intuitiva.

O projeto também possui uma funcionalidade de calendário, permitindo visualizar datas e organizar melhor as atividades.

Este projeto faz parte da minha jornada de aprendizado em programação e representa a aplicação prática dos conhecimentos adquiridos durante meus estudos.

## ⚙️ Funcionalidades

* 📝 Gerenciamento de tarefas
* 📅 Visualização de calendário
* 🖥️ Interface gráfica
* ⚠️ Validação de informações
* 🔧 Tratamento de erros
* 📋 Organização de tarefas

## 🛠️ Tecnologias utilizadas

* 🐍 **Python**
* 🎨 **CustomTkinter**
* 🖼️ **Tkinter**

## ▶️ Como executar

### 1. Clone o repositório

```bash
git clone https://github.com/NaylaSoouza/Agenda-Python.git
```

### 2. Acesse a pasta do projeto

```bash
cd Agenda-Python
```

### 3. Acesse a pasta da aplicação

```bash
cd app_final
```

### 4. Execute o programa

```bash
python p2.py
```

> É necessário ter o **Python instalado** no computador.
